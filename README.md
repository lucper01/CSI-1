# CSI-1 - Luc Perroquin

Support du premier Comité de Suivi Individuel.

## Architecture

- `index.html` contient à lui seul toute la présentation et tout son code.
- `affiches/` contient uniquement les fiches projets PDF ouvertes depuis les slides.
- `assets/` contient les rares ressources média utilisées par la présentation.

Il n’existe plus de versions parallèles, de loaders JavaScript, de fragments compressés ou de pages de présentation dupliquées.

Présentation : https://lucper01.github.io/CSI-1/
