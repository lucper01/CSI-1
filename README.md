# CSI 1 - Présentation de suivi de thèse

Présentation web du premier Comité de Suivi Individuel de Luc Perroquin, publiée via GitHub Pages.

## Version actuelle

La présentation conserve `presentation-base.html` comme base autonome stable et applique les évolutions du CSI-1 via `csi-v9.js`.

Principales caractéristiques de la version actuelle :

- page de garde enrichie avec les membres du Comité de Suivi Individuel et les identités institutionnelles ;
- membres du CSI : Fabrice Damon et Camille Ferdenzi-Lemaître ;
- page de remerciements dédiée ;
- bouton `Q` dans le header donnant accès à un espace de diapositives cachées pour les réponses spécifiques ;
- espace `Q` volontairement vide pour le moment ;
- ordre opérationnel 2026-2027 : **SOFT -> OASIS -> TWIXOLF** ;
- rétroplanning mis à jour avec OASIS avant TWIXOLF ;
- chronologie narrative réorganisée afin de présenter les contraintes et difficultés expérimentales avant les perspectives ;
- communications envisagées : Nuit des chercheurs 2026, Fête de la Science 2026, Expérimentarium 2027, FJC 2027 et JDD 2027 ;
- nouvelle slide d'appareillage avec CyNexo Sniff-0, BioSemi ActiveTwo et BIOPAC MP160 ;
- références courtes ajoutées aux principales slides théoriques et expérimentales ;
- slides longues rendues verticalement défilables afin d'éviter les contenus coupés hors plein écran ;
- slide de discussion compactée en grille responsive.

## Navigation

En mode diapo :

- `←` : slide précédente ;
- `→` : slide suivante ;
- `Q` dans le header : ouvrir l'espace de réponses spécifiques.

Les autres fonctions de l'interface restent disponibles : sommaire, vue d'ensemble, notes, plein écran et personnalisation.

## Fichiers

- `index.html` : point d'entrée GitHub Pages ;

- `csi-v9.js` : contenu, ordre narratif et adaptations du CSI-1 ;
